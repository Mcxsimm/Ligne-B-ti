# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

Projet : site de vente de **ChargéPro** (outil de pilotage pour chargés d'affaires du bâtiment). Site statique HTML/CSS/JS natif, sans framework.

## Aesthetic reference

- **Standard:** Stripe <!-- Linear | Stripe | Apple Native | Raycast | Notion | Custom -->
- **Notes:** Typographie nette (Inter, chiffres tabulaires), hiérarchie forte, profondeur légère (filet 1px + ombre douce), grands visuels produit réels (captures de ChargéPro en mode démo). Palette reprise de l'application : bleu marine `#12335C` (marque), orange `#E8590C` (accent rare : logo, repères), neutres froids. Thème clair par défaut, thème sombre automatique.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs
- Faux témoignages, faux logos clients ou chiffres inventés : seules des informations vérifiables sur le produit sont affichées
- Captures retouchées ou maquettes fictives : uniquement de vraies captures de l'application

## Accessibility target

- **Level:** WCAG 2.1 AA <!-- WCAG 2.1 AAA | WCAG 2.1 AA -->
- **Contrast:** ≥ 4,5:1 pour le texte courant, ≥ 3:1 pour les grands titres, bordures de champs et icônes utiles. L'orange `#E8590C` ne sert jamais au petit texte sur fond clair (utiliser `--accent-text`).
- **Touch / focus:** cibles ≥ 44×44 px ; anneau de focus visible 2px (`--focus`) avec décalage, jamais supprimé.

## Brand tone and microcopy voice

- **Voice:** Opinionated & Direct <!-- Utilitarian & Minimal | Warm & Humancentric | Opinionated & Direct -->
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Phrases courtes, orientées bénéfice, vocabulaire du métier (chantier, devis, BTE, OTP, BPU, RAF). Vouvoiement. Aucune promesse non vérifiable. Boutons = verbe + objet (« Demander une démo », « Essayer la démo »).

## Icon library

- **Library:** Project SVG <!-- Lucide | Heroicons | Phosphor | Tabler | Radix Icons | Remix Icon | Project SVG | None -->
- **Package / path:** SVG inline dans les pages (trait 1,6–1,75 px, `viewBox 0 0 24 24`, `stroke="currentColor"`, style Lucide)
- **Notes:** Aucun paquet installé. Garder un seul style de trait ; pas d'emoji comme icône.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
